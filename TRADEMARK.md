# MetaMeld™ — trademark policy

The MetaMeld code is MIT-licensed. **The name is not.**

MIT is a copyright licence. It says nothing about trademarks, and its
"deal in the Software without restriction" wording is broad enough that
people reasonably assume the name travels with the code. It does not.
This file is here to say so plainly, so nobody has to guess.

**MetaMeld** and the MetaMeld logo are trademarks of DuckySonadar. All
rights in the name are reserved. Copying the software does not grant any
right to use the name.

## What you may do without asking

- **Use the software**, for anything, commercially or not. That is what
  the MIT licence is for, and nothing here narrows it.
- **Redistribute it unmodified**, under the name MetaMeld, with the
  copyright notice intact.
- **Say true things.** "Built with MetaMeld", "imports MetaMeld files",
  "a MetaMeld plugin", "compatible with MetaMeld" are all fine. So is
  naming it in documentation, articles, tutorials and comparisons.
- **Name a plugin after what it does**, and say what it plugs into:
  *Fish Designer for MetaMeld* — good. *MetaMeld Fish* — not, because it
  reads as ours.

## What needs permission

- **Naming a fork MetaMeld**, or anything close enough to be confused
  with it. Fork freely — the licence says you may — but give it your own
  name. Say "based on MetaMeld" instead.
- **A modified version distributed as MetaMeld.** If you have changed it,
  the name has to change too, so that a bug in your build is not our
  reputation.
- **Using the name in your product name, company name or domain**, or in
  a way that suggests we made, endorse or support your thing.
- **The logo**, in any form, for anything.

## Why

The point is not to restrict the code. The code is MIT and will stay MIT:
take it, embed it, sell what you build with it, owe nobody anything. The
point is that when someone downloads something called MetaMeld, they get
the thing we made, in the state we shipped it. That guarantee is the only
thing the name is for.

## Getting permission

Ask. Uses outside the list above are usually fine and are usually granted;
the reason they need asking is so there is a record of who is using the
name and for what.
